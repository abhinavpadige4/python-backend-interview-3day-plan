## Study Plan

## How to Use
1. Follow the 3-day study plan in `STUDY_PLAN.md`
2. Attempt each problem before looking at the solution
3. Review time/space complexity analysis in each solution
4. Practice explaining your approach out loud
5. Use the SQL solutions to practice database querying concepts
